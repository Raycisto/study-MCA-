Definition

Machine Learning (ML) is a subset of Artificial Intelligence that gives computers the ability to learn from data without being explicitly programmed for every task. Coined by Arthur Samuel in 1959, ML systems improve their performance with experience.

Arthur Samuel, 1959

"Machine Learning is the field of study that gives computers the ability to learn without being explicitly programmed."

Tom Mitchell, 1997

"A computer program is said to learn from experience E with respect to some task T and performance measure P, if its performance on T, as measured by P, improves with E."

Scope of Machine Learning

Pattern Recognition

ML algorithms identify patterns and regularities in data to make predictions or decisions.

Generalization

Learning from training data to perform well on unseen/new data — the ultimate goal.

Automation

Automate complex decision-making tasks that are hard to code with explicit rules.

Data-Driven

Unlike traditional programming, ML derives its rules from data itself.

1. Supervised Learning

The model learns from labelled training data — each training example has an input and a known correct output (label). The algorithm learns a mapping function from inputs to outputs.

  • Uses labelled data (X → y pairs)
  • Tasks: Classification (discrete output) and Regression (continuous output)
  • Examples: Spam detection, house price prediction, image recognition
2. Unsupervised Learning

The model learns from unlabelled data, discovering hidden patterns and structures on its own without any predefined output labels.

  • No labels — model discovers structure
  • Tasks: Clustering, dimensionality reduction, association rule mining
  • Examples: Customer segmentation, anomaly detection, topic modelling
3. Semi-Supervised Learning

Uses a small amount of labelled data combined with a large amount of unlabelled data during training. Useful when labelling is expensive or time-consuming.

  • Combines supervised and unsupervised approaches
  • Examples: Medical image classification with few labelled scans, web content classification
  • Common approach: Self-training, co-training, generative models (GANs)
4. Reinforcement Learning

An agent learns by interacting with an environment, taking actions to maximize cumulative reward. No labelled data — learning happens via trial and error.

Key Components Agent → Action → Environment → State + Reward → Agent (loop)
  • Agent, Environment, State, Action, Reward, Policy
  • Algorithms: Q-Learning, SARSA, Deep Q-Network (DQN), PPO
  • Examples: Chess/Go (AlphaGo), robot locomotion, game playing (Atari)

What is Linear Regression?

Linear regression models the linear relationship between a dependent variable (y) and one or more independent variables (X). It predicts a continuous numeric output.

Simple Linear Regressiony = β₀ + β₁x + ε
β₀ = intercept (bias), β₁ = slope (weight), ε = error term

Multiple Linear Regressiony = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε
Ordinary Least Squares (OLS)

OLS finds β values that minimize the Sum of Squared Residuals (SSR) — the squared difference between actual and predicted values.

Cost Function — MSEJ(β) = (1/n) Σ (yᵢ − ŷᵢ)²

Closed Form Solutionβ = (XᵀX)⁻¹ Xᵀy

Assumptions

  • Linearity — linear relationship
  • Independence — observations independent
  • Homoscedasticity — constant error variance
  • Normality — errors normally distributed
  • No multicollinearity — predictors uncorrelated

Evaluation Metrics

  • MAE — Mean Absolute Error
  • MSE — Mean Squared Error
  • RMSE — Root Mean Squared Error
  • R² — Coefficient of Determination (0–1)
  • Adjusted R² — penalises extra features
Sklearn Implementation
Python from sklearn.linear_model import LinearRegression from sklearn.metrics import mean_squared_error, r2_score import numpy as np model = LinearRegression() model.fit(X_train, y_train) y_pred = model.predict(X_test) print(f"R²: {r2_score(y_test, y_pred):.4f}") print(f"RMSE: {np.sqrt(mean_squared_error(y_test, y_pred)):.4f}")
Why Polynomial Regression?

When the relationship between variables is non-linear, linear regression fails. Polynomial regression extends linear regression by adding polynomial terms (x², x³, …) as features.

Degree-2 Polynomialy = β₀ + β₁x + β₂x² + ε

Degree-d Polynomialy = β₀ + β₁x + β₂x² + ... + βdxᵈ + ε
Overfitting & Degree Selection
  • Low degree → Underfitting (high bias, doesn't capture pattern)
  • Right degree → Good fit (captures the true pattern)
  • High degree → Overfitting (high variance, memorises noise)
Python from sklearn.preprocessing import PolynomialFeatures from sklearn.pipeline import Pipeline poly_model = Pipeline([ ('poly', PolynomialFeatures(degree=3)), ('linear', LinearRegression()) ]) poly_model.fit(X_train, y_train)

Term Meaning Cause Problem
Bias Error from wrong assumptions Too simple model Underfitting
Variance Sensitivity to training data Too complex model Overfitting

k-Fold Cross-Validation

Instead of a single train/test split, k-Fold CV divides data into k equal folds. The model trains k times, each time using k−1 folds for training and 1 fold for validation.

CV ScoreCV_score = (1/k) Σᵢ score(fold_i)
Python from sklearn.model_selection import cross_val_score scores = cross_val_score(model, X, y, cv=5, scoring='r2') print(f"CV Mean: {scores.mean():.4f} ± {scores.std():.4f}")
Theory

Despite the name, logistic regression is a classification algorithm. It models the probability that an input belongs to a class using the sigmoid function, squashing output between 0 and 1.

Sigmoid Functionσ(z) = 1 / (1 + e⁻ᶻ) where z = β₀ + β₁x₁ + ... + βₙxₙ

Decision RulePredict class 1 if P(y=1|X) ≥ 0.5, else class 0

Loss Function — Binary Cross-EntropyL = −(1/n) Σ [yᵢ log(ŷᵢ) + (1−yᵢ) log(1−ŷᵢ)]
Classification Metrics

Confusion Matrix

TP: True Positive  |  FP: False Positive
TN: True Negative  |  FN: False Negative

Derived Metrics

  • Accuracy = (TP+TN)/(TP+FP+TN+FN)
  • Precision = TP/(TP+FP)
  • Recall = TP/(TP+FN)
  • F1-Score = 2·(P·R)/(P+R)
  • AUC-ROC — area under ROC curve
Algorithm

k-NN is a non-parametric, lazy learning algorithm. To classify a new point, it finds the k nearest neighbours in the training set and assigns the majority class (classification) or average value (regression).

Euclidean Distanced(x, xᵢ) = √( Σ (xⱼ − xᵢⱼ)² )

Other DistancesManhattan: Σ |xⱼ − xᵢⱼ| Minkowski: (Σ |xⱼ − xᵢⱼ|ᵖ)^(1/p)
  • k=1 — very flexible, high variance (overfits)
  • k=large — smooth boundary, high bias (underfits)
  • Best k — found via cross-validation (odd number preferred for binary)
  • Feature scaling (StandardScaler) is essential for k-NN
How Decision Trees Work

Decision Trees split data into subsets recursively using feature-value thresholds. Each internal node is a feature test; leaves are class labels or values.

Entropy (impurity measure)H(S) = −Σ pᵢ log₂(pᵢ)

Information GainIG(S, A) = H(S) − Σ (|Sᵥ|/|S|) · H(Sᵥ)

Gini ImpurityGini(S) = 1 − Σ pᵢ²

Splitting Criteria

  • ID3 — uses Information Gain
  • C4.5 — uses Gain Ratio
  • CART — uses Gini Impurity (sklearn default)

Hyperparameters to Tune

  • max_depth — limits tree depth
  • min_samples_split — min samples to split
  • min_samples_leaf — min samples at leaf
  • max_features — features considered at split
Core Idea

SVM finds the optimal hyperplane that maximises the margin between classes. The margin is the distance between the hyperplane and the nearest data points of each class (called support vectors).

Decision Boundary (Linear)wᵀx + b = 0

MarginMargin = 2 / ||w|| → Maximise margin = Minimise ||w||

Objective (Hard Margin)Minimise: (1/2)||w||² subject to: yᵢ(wᵀxᵢ + b) ≥ 1
Kernel Trick

For non-linearly separable data, SVM uses the kernel trick to implicitly map data to a higher-dimensional space where it becomes linearly separable.

Kernel Formula Use Case
Linear K(x,z) = xᵀz Linearly separable data
Polynomial K(x,z) = (xᵀz + c)ᵈ Polynomial decision boundary
RBF/Gaussian K(x,z) = exp(−γ||x−z||²) Most non-linear problems
Sigmoid K(x,z) = tanh(αxᵀz + c) Neural network-like

Unsupervised Learning

Clustering · Dimensionality Reduction · Association Rules

Algorithm Steps
  • Step 1: Choose k and randomly initialise k centroids
  • Step 2: Assign each point to the nearest centroid (Euclidean distance)
  • Step 3: Recompute centroids as the mean of all assigned points
  • Step 4: Repeat steps 2–3 until centroids don't change (convergence)
Objective — Minimise WCSSJ = Σₖ Σₓ∈Cₖ ||x − μₖ||² where μₖ = centroid of cluster k
Choosing k — The Elbow Method

Plot WCSS vs k. The optimal k is at the "elbow" — where the rate of decrease sharply changes.

Limitations of K-Means

  • Must specify k beforehand
  • Sensitive to outliers and initialization
  • Assumes spherical clusters of equal size
  • May converge to local minima (use k-means++)

Evaluation Metrics

  • WCSS / Inertia — sum of squared distances
  • Silhouette Score — [-1,1], higher is better
  • Davies-Bouldin Index — lower is better
Python from sklearn.cluster import KMeans kmeans = KMeans(n_clusters=3, init='k-means++', random_state=42) kmeans.fit(X) labels = kmeans.labels_ centers = kmeans.cluster_centers_
Agglomerative (Bottom-Up) Approach
  • Start with each point as its own cluster
  • Repeatedly merge the two closest clusters
  • Continue until all points are in one cluster
  • Cut the dendrogram at desired level to get k clusters
Linkage Methods
Linkage Distance Measure Best For
Single Min distance between clusters Non-convex shapes

Average Mean distance between clusters General purpose
Ward Minimise within-cluster variance Most common, compact clusters
Key Advantage

No need to specify k upfront. The dendrogram reveals the natural hierarchical structure of data.

How DBSCAN Works

DBSCAN groups together points that are closely packed, and marks points in low-density regions as outliers/noise. It doesn't require specifying k upfront.

Parameters

  • ε (epsilon) — neighbourhood radius
  • MinPts — min points in ε-neighbourhood to be a core point

Point Types

  • Core point — ≥ MinPts within ε
  • Border point — < MinPts but reachable from core
  • Noise point — neither core nor border (outlier)

What is PCA?

PCA transforms high-dimensional data into fewer dimensions (principal components) while retaining maximum variance. Each principal component is an orthogonal linear combination of original features.

PCA Steps1. Standardize data (zero mean, unit variance) 2. Compute covariance matrix: C = (1/n) XᵀX 3. Compute eigenvectors and eigenvalues of C 4. Sort eigenvectors by eigenvalue (descending) 5. Select top k eigenvectors (principal components) 6. Project data: Z = X · W (W = selected eigenvectors)
Python from sklearn.decomposition import PCA pca = PCA(n_components=2) X_pca = pca.fit_transform(X) print(pca.explained_variance_ratio_) print(pca.explained_variance_ratio_.cumsum())
t-SNE

t-SNE is a non-linear dimensionality reduction technique primarily used for visualisation of high-dimensional data in 2D or 3D. It preserves local structure (nearby points stay nearby).

  • Models pairwise similarities in high-dim space using Gaussian distributions
  • Uses t-distribution in low-dim space to avoid crowding problem
  • Perplexity hyperparameter controls local vs global structure (try 5–50)
  • Not suitable for new data projection — use PCA + t-SNE for large datasets
Apriori Algorithm

Apriori mines frequent itemsets and generates association rules from transactional data (e.g., market basket analysis).

Key MeasuresSupport(A→B) = P(A∩B) = freq(A,B) / N Confidence(A→B) = P(B|A) = freq(A,B) / freq(A) Lift(A→B) = Confidence(A→B) / Support(B)

Apriori Principle

If an itemset is frequent, all its subsets must also be frequent. Prunes search space by discarding infrequent subsets early.

Interpretation of Lift

  • Lift > 1 → positive correlation
  • Lift = 1 → independent
  • Lift < 1 → negative correlation

Artificial Neuron (Perceptron)

Inspired by biological neurons, an artificial neuron takes multiple weighted inputs, sums them (plus a bias), passes through an activation function, and produces an output.

Neuron Outputz = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = wᵀx + b output = activation(z)
Activation Functions
Function Formula Range Use Case
Sigmoid 1/(1+e⁻ᶻ) (0,1) Binary output layer
Tanh (eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ) (−1,1) Hidden layers (zero-centred)
ReLU max(0,z) [0,∞) Hidden layers (most common)
Leaky ReLU max(αz,z), α=0.01 (−∞,∞) Fixes dying ReLU
Softmax eᶻⱼ/Σeᶻₖ (0,1), sums to 1 Multi-class output layer
Dying ReLU Problem

If z < 0 always, ReLU outputs 0 and gradient is 0 — the neuron stops learning. Leaky ReLU, ELU, and SELU address this.

Loss Functions Overview
Loss Function Formula Used For
MSE (1/n)Σ(yᵢ−ŷᵢ)² Regression
MAE (1/n)Σ|yᵢ−ŷᵢ| Regression (robust)
Binary Cross-Entropy −Σ[y log(ŷ)+(1−y)log(1−ŷ)] Binary classification
Categorical Cross-Entropy −Σ yᵢ log(ŷᵢ) Multi-class classification
Hinge Loss max(0, 1−y·ŷ) SVM / binary classif.
Key Insight

MSE penalises large errors heavily (squares them). Cross-entropy is preferred for classification because it directly measures the probability distribution mismatch.

Backpropagation

Backpropagation computes gradients of the loss w.r.t. each weight using the chain rule, propagating errors from output layer back to input layer.

Chain Rule∂L/∂w₁ = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂w₁)
  • Forward pass — compute predictions layer by layer
  • Compute loss — compare predictions to true labels
  • Backward pass — compute gradients via chain rule
  • Update weights — apply gradient descent

Why RNNs?

RNNs are designed for sequential data (text, time series, audio). Unlike feedforward networks, RNNs have recurrent connections that pass information from previous time steps.

RNN Computationhₜ = tanh(Wₕhₜ₋₁ + Wₓxₜ + b) ← hidden state yₜ = Wyh hₜ + by ← output
LSTM & GRU

LSTMs solve the vanishing gradient problem using a cell state and three learnable gates.

LSTM Gates

  • Forget gate: f = σ(Wf·[h,x]+b)
  • Input gate: i = σ(Wi·[h,x]+b)
  • Output gate: o = σ(Wo·[h,x]+b)
  • Cell state: Cₜ = f⊙Cₜ₋₁ + i⊙C̃ₜ

GRU (Gated Recurrent Unit)

  • Simplified LSTM with 2 gates
  • Reset gate + Update gate
  • Fewer parameters, trains faster
  • Often comparable performance to LSTM

Bias in ML

Types of Bias

  • Historical bias — data reflects past discrimination
  • Sampling bias — unrepresentative training data
  • Measurement bias — systematically wrong measurements
  • Algorithmic bias — model architecture introduces bias

Real-World Examples

Pre-train on large datasets, fine-tune on specific tasks. Reduces data and compute requirements dramatically.

Train models across decentralised devices without centralising raw data. Privacy-preserving by design.

Automatically selects models, preprocesses data, and tunes hyperparameters. Tools: Auto-sklearn, H2O.ai, Google AutoML.

🎨 Generative AI

GANs, VAEs, Diffusion models. Generates images, text, audio, video. DALL-E, Stable Diffusion, Midjourney.

🔬 Explainable AI (XAI)

Methods to make ML decisions interpretable. SHAP, LIME, attention maps. Mandated by regulations.

🌱 Edge ML / TinyML

Running ML models on low-power edge devices (IoT, smartphones). Frameworks: TensorFlow Lite, ONNX, Core ML.
